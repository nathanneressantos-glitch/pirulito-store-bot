# 🍬 Pirulito Store Bot

Bot oficial da Pirulito Store.

## Produtos
- FFlags
- Otimizações
- Corpos
- Contas
- Seja VIP
- Seja Vendedor

## Comandos
- /painel — publica o painel de compras
- /preco — configura o preço de um produto
- /estoque — adiciona itens ao estoque

## Configuração
O bot usa Node.js e discord.js.
Configure as variáveis de ambiente:
- DISCORD_TOKEN
- CLIENT_ID
- GUILD_ID
